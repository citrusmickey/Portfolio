# Mickey — Portfolio

A 3D-creator style personal portfolio landing page for **Mickey**, a front-end web developer.
Bubblegum **Y2K** theme with holographic gradients, sparkle animations, and a sparkle cursor trail.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (dev/build)
- **Tailwind CSS**
- **Framer Motion** (scroll & entrance animations)
- **Lucide React** (icons)

## Sections

Hero · Marquee · About · Experience · Projects · Contact

## Getting Started

```bash
npm install
npm run dev      # start dev server
npm run build    # type-check + production build
npm run preview  # preview the production build
```
